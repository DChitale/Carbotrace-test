# 🚀 Carbotrace Test Repository

This is a demonstration repository to test **Carbotrace Carbon Audit** workflows, static AST analysis, CI/CD pipeline triggers, and Infrastructure-as-Code (Terraform) sustainability scoring.

## 📁 Repository Structure

- `src/main.py`: Sample Python application with nested loop logic and data processing.
- `src/index.js`: Sample Node.js web server logic.
- `terraform/main.tf`: AWS infrastructure definitions (EC2 & RDS).
- `.github/workflows/carbotrace.yml`: GitHub Actions PR Carbon Audit workflow.
